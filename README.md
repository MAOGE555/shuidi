# 工具简介

### 集成了抓包、扫描器、漏扫工具、子域名爆破、js探测、OA利用、框架利用、各类组件、jndi注入、内存马、内网渗透、webshell免杀、程序免杀、内网穿透、Windows溯源工具、Linux溯源工具等等。





# V11版本更新如下：
- 去除一些out工具，添加一些新工具（转子女神、jssfind、若依、Redis利用、jsmap等等）
- 输入框粘贴时，会带文本格式，现已统一格式
- 调整UI布局，工具分类更合理
- 更新了所有原有工具的版本
